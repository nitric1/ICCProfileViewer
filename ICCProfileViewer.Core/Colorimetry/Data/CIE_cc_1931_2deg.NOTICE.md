Commission on Illumination (CIE) open-access dataset:

- Publication year: 2019

The dataset covers 360–830 nm at 1 nm intervals. The surrounding application
code parses the dataset and derives CIE 1976 u′v′ coordinates without modifying
the redistributed CSV.
